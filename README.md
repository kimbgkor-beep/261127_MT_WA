# 철도 위험기상 모니터링 웹앱 (Flask)

`rail_weather.py` 기반의 철도 위험기상 모니터링 기능을 Flask 웹 애플리케이션으로 구현하고, 반응형 UI와 연속 열차 이동 시뮬레이션을 추가한 프로젝트입니다.

## 주요 기능

- **지리공간 연산 백엔드 (`geo_service.py`, `app.py`)**
  - 경부선, 호남선, 강릉선, 중앙선, 전라선 경로 및 약 500m 간격 보간 좌표 생성
  - `shapely` & `pyproj` 기반 5km 단일/중복 영향 범위 GeoJSON 생성
  - 철도 반경 5km 이내 50개 가상 기상관측소(AWS) 및 위험기상 구역(대설·호우·강풍) API 제공
- **반응형 웹 UI (`업그레이드 1`)**
  - 데스크톱: 상단 요약 바 + 전체 지도 + 우측 모니터링 사이드바
  - 태블릿/모바일(`<= 900px`): 전체 지도 + 접이식 하단 시트(Bottom Sheet) 드로어
- **연속적인 열차 이동 시뮬레이션 (`업그레이드 2`)**
  - `requestAnimationFrame`과 구간 거리 기반 선형 보간으로 60fps 연속 이동 구현
  - 배속 조절 (`0.5x`, `1x`, `2x`, `4x`), 일시 정지/재개, 열차 클릭 시 지도 추적

## 실행 방법

```bash
cd webapp
py app.py
```

브라우저에서 `http://127.0.0.1:5000` 접속
